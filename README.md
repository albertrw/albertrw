## Flagship

**[IoT Dashboard Platform](https://github.com/albertrw/iot-dashboard)** — monitor and control connected devices in real time.

```text
  device  ──▶  mqtt broker  ──▶  api  ──▶  postgres  ──▶  live dashboard
     ▲                            │
     └────────── commands ────────┘
```

Secure device registration, live telemetry over WebSockets, offline detection, and role-based access.

`React` `TypeScript` `Node.js` `Express` `PostgreSQL` `MQTT` `WebSockets` `Tailwind`
